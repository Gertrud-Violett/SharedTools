# FTA Editor の例題（福島第一原子力発電所の全交流電源喪失、学習用）

まきブログの故障の木解析（FTA）の記事で使った、故障の木のファイルです。
[FTA Editor](https://github.com/Gertrud-Violett/FTA_Editor) で開けます（バージョン 1.9.2 で確認）。

Fault trees used in a Makkiblog article (in Japanese) on fault tree analysis, with the loss of all AC power at Fukushima Daiichi as the example. **They are simplified learning examples, not a re-evaluation of the accident or of the plant's risk.**

## はじめにお読みください

- **学習用に単純化した木です。** 発電所や事故のリスクを評価し直したものではありません。1つの号機だけを見ており、号機の間の電源の融通、外部電源の復旧、直流電源（蓄電池）は入れていません。
- **故障の値は米国の統計です。** 日本の発電所の実績ではありません。値、単位、出典、データの期間は、各事象のメモに書いてあります。
- **津波の確率は入れていません。** 「津波による浸水」の確率 1 は「浸水が起きたとして」という意味で、津波の起こりやすさの見積もりではありません。確率 1 を入れると、FTA Editor の「検証」タブに警告が出ます。
- **値が 0 の事象は、出典の表に値がないものです。** 現実の値ではありません（故障を無視する単純化）。
- 頂上事象の値の単位は「1炉臨界年あたり」です（外部電源喪失の値の単位によります）。

## ファイル

| ファイル | 内容 | 頂上事象 |
|---|---|---|
| `fukushima_1_independent.json` | 全交流電源喪失 = 外部電源喪失 AND（EDG A が使えない AND EDG B が使えない）。2台の非常用ディーゼル発電機（EDG）を独立とした木 | 2.27e-5（ツリー計算） |
| `fukushima_2_ccf.json` | 1の木に、共通原因故障（βファクタ）のグループを、故障モードごとに3つ足したもの | 2.77e-5（MCUB） |
| `fukushima_3_flood.json` | 各系統に海水ポンプ、高圧配電盤（M/C）、低圧配電盤（P/C）を足し、1つの事象「津波による浸水」をリンクでつないだ木。浸水の確率は 1 | 0.0359（MCUB） |
| `fukushima_4_air_cooled.json` | 空冷の EDG 3台（2B、4B、6B）の系統を並べた木。2B と 4B は配電盤が浸水し、6B は浸水していない | 系統ごとの値を見ます（2B と 4B は 1、6B は 0.0251） |

頂上事象の値は、FTA Editor 1.9.2 の画面上部に出る値です。同じ事象が2か所以上に出てくる木と、共通原因故障のグループがある木では、MCUB（最小カット上限）になります。

空冷の EDG と配電盤の設置場所、浸水の有無は、東京電力「福島原子力事故調査報告書」（2012年6月20日）によります。ページは各事象のメモに書いてあります。

## 開き方

1. ファイルを、自分のホームフォルダー（`C:\Users\ユーザー名`）の中に保存します。FTA Editor の「読込」で開けるのは、初期設定ではホームフォルダーの中だけです。
2. FTA Editor を起動して、画面下の「読込」からファイルを選びます。
3. 最小カットセットや重要度を見るときは、画面上部の「詳細機能」をオンにします。
